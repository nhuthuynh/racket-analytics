| 2026-10-29 | sre-devops-engineer | **Root cause: per-port `free_port()`** bound port 0, printed it and closed the socket, once per port (8 calls), so two flags could get the same port and a parallel weed could take a port between choice and bind | Real SeaweedFS 3.97 with its filer port held by another process reproduces the CI line exactly (first red run of `test_real_weed_survives_a_port_taken_by_another_process`: "Filer listener error: listen tcp 127.0.0.1:47367: bind: address already in use") | #150's change is unrelated; the failure is a race in the test infrastructure |
| 2026-10-29 | sre-devops-engineer | **Allocate all 8 ports in ONE python call that keeps every socket bound until all are chosen** (`alloc_ports`, exposed as `dev-objectstore.sh ports N`) | `test_one_allocation_never_repeats_a_port` (60 allocations of 8), `test_a_large_allocation_is_still_distinct` (256), scenario "Every port given to the object store is distinct" | The kernel cannot return a port that is still bound, so duplicates inside one start are impossible |
| 2026-10-29 | sre-devops-engineer | **Retry only when the weed log contains "address already in use"**, on fresh ports, at most 3 retries (4 starts), each logged `port collision, retry n/3 with fresh ports`; data dir and state file of the failed try are removed | `test_a_collision_is_retried_with_fresh_ports`, `test_a_collision_that_persists_fails_after_three_retries`, real-weed integration test, scenarios 2 and 3 | One allocation cannot stop another process taking a port before weed binds it; a bounded retry closes that window without hiding other faults |
| 2026-10-29 | sre-devops-engineer | **Every other startup failure fails closed at once, unchanged** (same "weed exited during startup" message and weed log tail; "S3 not ready" timeout is not retried) | `test_a_failure_that_is_not_a_port_collision_is_not_retried`, scenario 1 | A retry must never mask a real fault (wrong binary, bad dir, auth) |
| 2026-10-29 | sre-devops-engineer | **Test with a stand-in weed for the retry logic, plus one real-SeaweedFS case** (a wrapper holds the master port on the first start only) | `infra/tests/objstore_ports_fixtures.py`; `test_real_weed_survives_a_port_taken_by_another_process` | The stand-in makes collision counts deterministic and fast; the real case proves the wording the retry keys on is what SeaweedFS 3.97 prints. Both cases print `bind: address already in use` |
