Per-ticket decision file (PO rule 2026-10-07). Ticket: `make demo` seeds a ready-to-explore sample match so a fresh local stack shows stats immediately (PO MVP goal 2026-10-15).

Every rule (I5 times, I6 responsible player, scoring, stats) stays the API's; the demo only says what a player would tap |

No new binary, no ffmpeg/Docker dependency at run time. `--file` takes another clip |
| 2026-10-16 | senior-backend-engineer | 12 rallies of game 1, side A serving first, fixed in `scripts/demo/demoplan.py`: winners, unforced/forced errors and faults for both sides, one replay, some rallies without a player | Every published metric (AN-01..AN-07) gets a sample on both sides, and game 1 is still running after rally 12 (checked with taglib's independent stepper) |
| 2026-10-16 | senior-backend-engineer | Idempotence: a complete "Demo match" (video received, >= 12 rallies) is reused and nothing is added; an incomplete one (interrupted run) is left alone and "Demo match (n)" is created; `--new` always creates the next "Demo match (n)" | Ticket: re-running does not duplicate, or clearly creates "Demo match (n)". Never deletes user data |
| 2026-10-16 | senior-backend-engineer | Dev-profile guard in two layers: (1) `infra/.env` APP_ENV must be `dev` and DEV_IDENTITY_ENABLED not false, checked before any request (exit 3); (2) the live `GET /dev/users` must answer (the API mounts `/dev/*` only with dev sign-in enabled), else exit 3 before anything is written | A stale or missing env file cannot let the demo through; the second scenario proves only GETs reach a stack without dev sign-in |
| 2026-10-16 | senior-backend-engineer | TLS: `make demo` copies only the web-tls root certificate out of the stack into `.local/demo/root.crt` (gitignored) and verifies the chain with it; no `-k`/insecure mode | ADR 0029, same as the CI E2E job |
| 2026-10-16 | senior-backend-engineer | Reuses `scripts/measure/livehttp.py` (Client) and `measurelib.py` (tus helpers) rather than a second HTTP client | One stdlib client already tested by the measurement harness (judgment) |
| 2026-10-16 | senior-backend-engineer | CI: a step in `web-checks` (chromium only), after the gated Playwright journeys, runs the demo scenarios and the `make demo` integration test against the job's Compose stack with RA_DEMO_BASE_URL set (fails closed, never skips there).
