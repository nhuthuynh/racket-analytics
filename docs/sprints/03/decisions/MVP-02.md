# MVP-02 decisions

Small decisions for ticket MVP-02 (tagging without a playable video records every rally, not only the first; MVP goal, PO 2026-10-15), one dated row each. One file per ticket (PO rule 2026-10-07).

| Date | Who | Decision | Evidence | Reasoning |
|---|---|---|---|---|
| 2026-10-16 | senior-frontend-engineer | **Rally times come from a framework-free `RallyClock` (`web/src/lib/tagging/clock.ts`).** The video's time when it plays; otherwise the page clock plus an offset that carries it on from the last tagged rally's end (offset only grows). T-01 treats the video as not playing when it has no metadata, has a media error (`video.error`), or the cannot-play notice is shown (`videoProblem`). Existing behaviour with a playable video is unchanged. | Red (main's T-01): `cd web && pnpm exec vitest run tests/unit/mvp-02-rally-clock.test.ts tests/unit/mvp-02-tag-without-video.test.tsx` → `3 failed, 1 passed` + `Failed to resolve import "@/lib/tagging/clock"` (`rally 1 end: 'The rally end must be after its start.'`, `rally 2 start: 'This rally starts before the end of r…'`); green → `8 passed`; full Vitest `689 passed` | The reducer's rule (a rally cannot start before the last one ended) is right; the clock fed it a frozen time. Carrying on from the last end keeps the rule and also covers rallies tagged earlier from the video (their times exceed the page clock) |
| 2026-10-16 | senior-frontend-engineer | **The E2E makes the video unplayable in every browser** (media request aborted; `readyState` 1, `currentTime` stuck at 0, `error` code 3, `canPlayType` ''), because CI's Chrome and WebKit decode H.264 and would not reproduce the live finding. The natural case (Playwright Chromium, no H.264 decoder, no stubs) was also run once as a scratch copy, not committed. | Live stack (`docker compose -p racket-mvp02 ... up -d --build --wait`, https://localhost:43102), Chromium: red on main's web image → `1 failed` (`getByRole('status').filter({ hasText: /^Rally 1:/ })` not found; page alert "Mark the rally end first."); green after rebuild → `1 passed`; natural scratch → `1 passed`; regression `quick-tag`, `keyboard-tagging`, `journey` → all passed. WebKit is not installed locally (`/opt/pw-browsers/webkit-2215` missing), left to CI | A stub of exactly the observed state is deterministic in both CI browsers; the natural run shows the stub matches reality |
