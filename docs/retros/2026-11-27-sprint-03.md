## 3. Start / Stop / Continue

### Continue (what went well)

- **The product is on `main` and works live.** Every promise to the player ran 5/5 on fresh accounts from `main`, with large latency margins (tag → stats p95 32.7 ms against 5 s). Coverage, mutation and the oracle all held or improved.
- **Ticket PRs worked as a delivery unit.** 71 PRs, median 1.6 h from open to merge, two verdicts and green `ci-gate` on 68 of them. DoD-done went from 0 for three sprints to 36.5 units.
- **CI FIRST held.** Each of the five red `main` runs was fixed by its own root-cause ticket before more feature merges (CI-DOMAIN-BUDGET, CI-E2E-MAIN-RED, CI-REDUNTIL-HANG with CI-OBJSTORE-SLOW, CI-E2E-JOURNEYS-TIMEOUT, CI-STALL-SCENARIO-RACE). No test was weakened: each fix had a TCR row or none was needed.
- **Fail-closed tools found the real gaps.** `open_defects.py`, `reconcile_due.py`, `merged_verdict.py` and `demo_test_report.py` turned "is the goal met?" into commands, and they are why the final count is trusted.
- **Reviews kept finding real defects** (two rounds of CHANGES REQUESTED on many PRs before APPROVE; the PR #24 dictionary findings; the PR-gate base-SHA bug, CI-POLICY-BASE).

### Stop

- Batch merges that skip `merge_ready.py` (M10).
- Opening a docs PR per verification round and leaving it unmerged (M9).
- Waiving the size limit by default (M11).

### Start
