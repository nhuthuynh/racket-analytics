## 3. Liked (what went well)

- **The prototype runs from a fresh checkout.** `make up` + `make demo` give a demo user with a match, stats and a 2-week plan with 6 sessions and 12 cited assignments. The demo is idempotent and the README walkthrough is checked (G04-06). Plan generation p95 is 59.5 ms against a 5 s target.
- **The plan is correct and honest.** 32 of 32 eval cases pass all 3 runs; golden 9/9; property test at 1,000 examples; determinism 3/3. Every assignment cites metric, value, n and rallies, and the limited-data note works.
- **Merge discipline held.** All 57 PRs merged through `merge_ready.py` with both verdicts on the merged head and `ci-gate` green, and none was batch-merged. Retro 3's M10 did not repeat.
- **Red-first is now enforced, not just claimed.** The `Red:` check (C4-RED) failed #142/#143, and the team rebuilt them instead of rewriting pushed history.
- **The gate tickets came first.** PE-4, SEC-4, COACH-4 and PM-4 merged within 3 hours of planning (2026-10-17), and PD-4 merged before any UI ticket started. Retro 3's M2 did not repeat.
- **CI FIRST held whenever a session was running.** Each push incident was fixed within about an hour by its own root-cause ticket (CI-OBJSTORE-PORT-RACE, CI-INFRA-BUDGET). No test was weakened: 7 PRs carried `qa-approved-test-change` from the QA step.
